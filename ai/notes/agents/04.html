智能体检索与分层记忆管理

核心原理

传统 RAG 只是机械地把用户原话拿去搜一次向量库，而 Microsoft AI Agents for Beginners 第 5 课(Agentic RAG)与第 13 课(Managing Agentic Memory) 强调了两大升级：

Agentic RAG（主动式检索）：智能体会自己评估检索回来的文档够不够用——如果第一次搜到的资料相关性低，Agent 会自主改写查询词(Query Rewrite)、拆解多跳子问题或切换数据源重新检索，直到收集齐证据再作答。

三层记忆架构(Memory Hierarchy)：将记忆划分为短期工作记忆（Working Memory / 当前会话上下文）、情景记忆（Episodic Memory / 历史历史交互摘要） 与长期语义记忆（Semantic Memory / 用户偏好、固定资产配置等结构化键值库）。

第 4 关实操练习题：设计私人理财顾问 Agent 的记忆读写与主动检索策略

任务背景

用户对理财 Agent 说：“按我上个月告诉你的风险承受等级，帮我看看今天刚发布的这只新债券基金适不适合买？”

通关硬性要求（满分 12.5 分）

1. 设计检索分流逻辑：从【长期用户画像记忆库】读取用户的历史风险等级与持仓偏好，同时通过【主动文档检索工具】查询今日新基金招募说明书（4.5 分）；

2. 设计 Agentic RAG 自检判定规则：若首次检索仅拿到基金名称而缺少“最大回撤、久期、信用评级分布”关键字段，自动生成二次精准检索词（5 分）；

3. 设计对话结束后的记忆更新机制(Memory Write-back)：判断本次对话中哪些新信息值得写入长期记忆，哪些仅保留在短期会话中（3 分）。

Step 3: 记忆写回策略(Memory Write-back)

- 写入长期语义记忆：仅当用户明确表达新的长期偏好变更（如“我今年刚生了宝宝，以后只买保本型产品”）时，调用 update_semantic_memory()。
