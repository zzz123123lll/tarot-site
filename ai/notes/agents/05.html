SOURCE READING / 来源精读

Microsoft 第 9 课 Metacognition：让 Agent 观察、评估并修正自己的推理；本关 PDF 把它工程化为 Generator → Validator → Refiner 三步。

逐点读懂

  1. 生成之后需要校验，不能把第一次生成直接当作最终结果。
  2. 校验可以包含确定性规则和语义核对。
  3. 失败时把错误反馈给 Refiner 做定向修复。
  4. 重试要有上限，超过上限转人工处理。

怎么对应本关练习

读第 9 课后，把练习里的 Validator 分成“硬规则”和“语义核对”两类，Refiner 只负责按反馈修复。

核心原理

为什么顶级 Agent 写出的代码或报告极少出错?因为它们不会把第一次生成的结果直接丢给用戶! 根据 Microsoft AI Agents for Beginners 第 9 课(Metacognition) 与 Agentic AI Masterclass 的 Execution Hooks 机制,元认知(Metacognition)是指让 Agent 具备“自我监控、自我评估与自我纠错”能力。核心实 现模式是构建 Actor-Critic(执行者-审查者)内部循环:当 Actor 生成初稿或 SQL/Python 代码后,先由验证 器(确定性单元测试 / 语法检查器 + Critic 审查提示词)按评分标准打分;只有全部指标达标才放行输出,否 则将具体报错信息喂回给 Actor 进行定向修复(上限 2‒3 轮)。
