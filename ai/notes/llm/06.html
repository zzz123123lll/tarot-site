核心原理

在 mlabonne/llm-course 第 6 章(Evaluation)与第 8 章(Model Merging) 中,有两个极具性 价比的进阶秘籍: 零 GPU 算力的模型融合(Model Merging with MergeKit):如果你手里有一个“擅长写代码的微调模型 A”和一个“擅长中文创意写作的微调模型 B”(两者同源,如均基于 Qwen-2.5-7B 微调),无需重新训 练,直接用 mergekit 工具通过 SLERP(球面线性插值)、TIES 或 DARE 算法将两者的权重矩阵按比例融 合,甚至用 FrankenMoE 拼装成混合专家模型,往往能凭空诞生出一个综合能力超越两者的全能模型! 科学评估与 Goodhart 定律避坑:“当一个评测指标变成刷榜目标时,它就不再是一个好指标。”公开基准 (如 MMLU、GSM8K)极易遭受训练数据污染(Data Contamination);使用大模型当裁判(LLM-as-a- Judge)时,又存在显著的位置偏见(倾向选第一个回答)与长度偏见(倾向选长篇大论)。

MergeKit DARE-TIES 权重融合配置与无偏评测设计

# merge_config.yaml ― 使用 DARE-TIES 融合金融微调版与 SQL 编程微调版

models:

- model: ./models/Llama-3.1-8B-Finance-SFT

parameters:

density: 0.55 # 随机丢弃 45% 微小增量参数,消除冗余冲突

weight: 0.60

- model: ./models/Llama-3.1-8B-SQL-SFT

parameters:

density: 0.55

weight: 0.40

merge_method: dare_ties

base_model: meta-llama/Meta-Llama-3.1-8B-Instruct

parameters:

int8_mask: true

dtype: bfloat16
