30 SECONDS / 30 秒看懂

这一关只解决一件事：同一个模型在不同业务下，怎样用采样参数控制“确定”还是“发散”。

  • 医疗 JSON 要确定性：temperature 低
  • 小说续写要多样性：temperature 高、top_p 截断长尾
  • 算法 Pass@5 要多次采样但保持语法正确

术语拆开

Temperature
控制概率分布平滑度，越低越确定。
Top-p

SOURCE READING / 来源精读

现代开源 LLM 普遍采用 Decoder-only Transformer，并引入 BPE、RoPE 与 GQA；生成阶段每步输出词表上的概率分布，由 Temperature 与 Top-p 等解码策略决定选词。

逐点读懂

  1. BPE 负责子词分词，RoPE 提供旋转位置编码，GQA 通过共享 K/V 头降低长文本 KV Cache。
  2. Temperature 控制分布平滑度：越低越确定，越高越发散。
  3. Top-p 动态截取累积概率达到 p 的候选词集合。
  4. 医疗 JSON 提取需要确定性，参考答案使用 temperature=0.0。

怎么对应本关练习

读本关时把“模型结构”和“解码参数”分开：前者决定能算什么，后者决定每一步怎么选词。

核心原理

在 mlabonne/llm-course 的 The LLM Scientist 第 1 章 与 Modern LLM Notebook 中,现代主流 开源大模型(如 Qwen3.5-9B / Llama 4、Qwen3.8 / Qwen3.5、DeepSeek-V4.1)均采用 Decoder-only Transformer 架 构 , 并 引 入 三 大 关 键 升 级 : BPE 子 词 分 词 器 ( Byte-Pair Encoding )、 旋 转 位 置 编 码 ( RoPE ) 以 及 大 幅 降 低 长文 本 推 理 KV Cache 显 存 占 用 的 分 组 查 询 注 意 力 ( GQA, Grouped-Query Attention)。而在生成阶段,模型每一步输出的是词表上的概率分布(Logits),最终选出哪个词取决于解码 采样策略(Decoding Strategies):Temperature 控制概率分布平滑度(越低越确定,越高越发散),Top-p (Nucleus Sampling) 动态截取累积概率达到 p 的候选词集合。
