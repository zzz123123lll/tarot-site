SOURCE READING / 来源精读

全量微调 8B 模型需要更新全部参数，显存开销大；LoRA 冻结原权重、旁路注入低秩矩阵，QLoRA 再把基座权重量化到 4-bit NF4。

逐点读懂

  1. LoRA 可训练参数通常不到原模型 1%–2%。
  2. r 决定低秩矩阵容量，常规 16/32，复杂任务 64/128。
  3. lora_alpha 常见经验法则是 1*r 或 2*r。
  4. target_modules 建议挂载 Transformer 全部 7 个线性投影层。

怎么对应本关练习

读本关时把“省显存”拆成三件事：低秩旁路、4-bit 基座、梯度检查点/分页优化器。

核心原理

全量微调(Full Fine-Tuning)一个 8B 模型需要更新全部 80 亿参数,加上优化器状态(AdamW) 和梯度,往往需要 60GB‒80GB 显存。而根据 mlabonne/llm-course 的 SFT 与 Unsloth 教程,LoRA(Low- Rank Adaptation)冻结原模型权重 W,仅在旁路注入两个低秩矩阵 A 与 B(可训练参数量通常不到原模型的 1%‒2%);QLoRA 更进一步,将冻结的基座模型权重量化为 4-bit NormalFloat (NF4),结合分页优化器 (Paged Optimizers)和 Unsloth 手写算子加速,让你用一张免费的 16GB Google Colab T4 显卡就能轻松微 调 Llama-3.1-8B 或 Qwen-2.5-7B!核心超参数有三个: r(LoRA Rank 秩):决定低秩矩阵的容量,常规任务取 16 或 32,复杂领域任务取 64 或 128。 lora_alpha(缩放系数):控制旁路权重的更新幅度,业界黄金经验法则是设为 lora_alpha = 1 * r 或 2 * r。 target_modules(挂载目标线性层):切勿只挂 q_proj, v_proj!现代最佳实践是挂载 Transformer 的全部 7 个核心线性投影层(q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj),效果最接近全 量微调。

单卡 16GB 显存 QLoRA 微调 8B 模型黄金配置脚本

from unsloth import FastLanguageModel

from trl import SFTTrainer

from transformers import TrainingArguments

# 1. 4-bit QLoRA 加载基座模型(权重仅占 ~5.5GB 显存)

model, tokenizer = FastLanguageModel.from_pretrained(

model_name="unsloth/Meta-Llama-3.1-8B-Instruct-bnb-4bit",

max_seq_length=2048,

load_in_4bit=True,

)

# 2. 挂载全 7 层线性投影层与 Unsloth 梯度检查点

model = FastLanguageModel.get_peft_model(

model,

r=16,

lora_alpha=32, # 2 * r 黄金比例

target_modules=["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"],

lora_dropout=0.0,

bias="none",

use_gradient_checkpointing="unsloth", # 节省 30% 激活值显存

)

# 3. 小步快跑 + 梯度累积实现等效 Batch Size = 2 * 8 = 16

training_args = TrainingArguments(

per_device_train_batch_size=2,

gradient_accumulation_steps=8,

warmup_ratio=0.05,

num_train_epochs=2,

learning_rate=2e-4,

lr_scheduler_type="cosine",

optim="adamw_8bit", # 8-bit 优化器大幅压缩状态显存

weight_decay=0.01,

fp16=not FastLanguageModel.is_bfloat16_supported(),

bf16=FastLanguageModel.is_bfloat16_supported(),

output_dir="./outputs"

)

得分要点拆解:完整配置 4-bit 加载、`r=16, alpha=32`、全 7 层 `target_modules` 与梯度检查点(5 分);

通过 `batch_size=2` 配合 `grad_accum=8` 实现等效 Batch=16 防 OOM(4.5 分);选用 `adamw_8bit`、

`lr=2e-4` 与 `epochs=2`(3 分)。
