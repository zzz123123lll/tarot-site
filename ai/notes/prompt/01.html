基础提示词结构

先分清 System 与 User，再把任务事实、约束和字数写清楚。

约 3 分钟·免费阅读·整理自 Anthropic Prompt Engineering Interactive Tutorial / DAIR.AI Prompt Engineering Guide·来源精读 ↓·直接做题 ↓

SOURCE READING / 来源精读

Messages API 至少需要 model、max_tokens、messages；每条 message 必须有 role 和 content；user/assistant 必须交替，第一条必须是 user；system 是独立参数。

逐点读懂

  1. system prompt 在用户问题之前提供 context、instructions、guidelines，不是 messages 数组里的一条消息。
  2. 官方说明：写得好的 system prompt 可以提升模型遵循规则的能力。
  3. 消息角色和交替顺序是 API 结构约束；格式错误会直接报错，而不是模型理解问题。
  4. 本关练习要求把身份/文风放 System，把任务事实与约束放 User。

怎么对应本关练习

读原文时先确认两件事：哪些内容属于 system 通道，哪些属于 user 通道。练习里的“全局身份/文风”对应 system；“时间、地点、亮点、媒体权益”对应 user。

例子在哪

核心原理

根据 Anthropic 官方交互式教程第 1 章，大模型交互由两大核心通道构成：一是系统提示词(System Prompt)，用于定义全局规则、AI 身份背景与持久边界；二是用户与助手交替消息(User /Assistant Turns)，用于传递具体任务与上下文。新手常犯的错误是将背景规则、参考资料与具体问题胡乱揉成一句话，导致模型抓不住核心任务。

踩坑写法 vs. 高手写法对比

新手踩坑写法：“帮我写一封给客户的道歉信，因为物流晚了三天，顺便说一下赔偿一张20元优惠券，别写太长，语气客气点。”（缺陷：缺少发件人身份、客户场景、具体字数上限与结构要求，生成内容极易充满翻译腔和套话。）高手结构化写法：将【全局身份与文风规范】放入 System 设定，将【任务目标 + 事实要素 + 约束条件】按清晰层级排列在 User 指令中：

【System 设定】你是一位拥有 8 年经验的精品电商客户关系主管，文风真诚、简洁、务实，绝不使用空洞的公关套话。

【User 指令】请为因暴雪导致包裹延误 3 天的客户撰写一封致歉私信。

必须包含以下事实：1. 延误原因（中转仓暴雪封路）；2. 最新进展（今日已恢复派送，预计明日送达）；3.补偿方案（已直接发放 20 元无门槛券至账户）。

约束条件：全文不超过 120 字，分为“致歉与进展”、“补偿说明”两小段。

第 1 关实操练习题：重构混乱的产品发布会邀请函指令

任务背景

你需要让 AI 帮一家智能硬件初创公司撰写一封发给科技媒体记者的新品体验会邀请邮件。待改造劣质 Prompt:“写个邮件邀请记者下周五下午两点来参加我们的智能戒指发布会，地点在深圳市南山区科技园A座3楼，会发伴手礼，快点写。”

通关硬性要求（满分 10 分）

1. 明确拆分【System 全局规范】与【User 任务指令】两部分（3 分）；

2. 在任务指令中结构化列出时间、地点、核心亮点（如睡眠与心率无感监测）及媒体专属权益（4 分）；

3. 明确邮件字数范围（如 150‒200 字）与结尾行动号召（RSVP 回复确认截止时间）（3 分）。

System 设定

你是一位资深科技公关(PR)总监，擅长为硬核科技产品撰写高打开率、言简意赅的媒体邀请函。你的文风专业得体、重点突出，绝不堆砌华而不实的形容词。

User 指令

请为我们即将举办的“AeroRing 智能健康戒指新品媒体品鉴会”撰写一封发给科技媒体主编的专属邀请邮件。

核心事实要素：

1. 活动时间：下周五（10 月 23 日）下午 14:00 - 16:30;

2. 活动地点：深圳市南山区高新科技园 A 座 3 楼发布厅；

3. 产品核心看点：仅重 2.8 克的全钛合金机身，实现医疗级睡眠分期与全天候心率变异性(HRV)无感监测；

4. 媒体专属权益：现场提供 1 对 1 研发负责人专访机位，并赠送价值 1,299 元的首发量产版智能戒指一枚作为评测样机。

格式与约束要求

- 包含一个吸引科技记者点击的【邮件标题】；

- 正文严格控制在 160 - 200 字之间，分为“核心看点”、“时间地点与权益”、“回执确认（请于下周三 18:00前回复邮件确认出席及戒圈尺码）”三小段；

- 不要输出任何开场解释，直接输出邮件标题与正文。

得分要点拆解

清晰划分了 System 角色文风与 User 具体任务（3 分）；完整结构化了 4 项活动事实要素（4分）；明确了字数区间、三段式结构与 RSVP 截止行动号召（3 分）。
