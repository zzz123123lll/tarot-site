核心原理

纯向量语义检索有一个致命短板：对精确专有名词、产品型号代码（如“错误码 ERR-4092-B”）、人名与法规条文编号非常不敏感！根据 RAG Zero to Hero Guide 与 RAG All-in-One 的进阶架构，工业级知识库普遍采用“两阶段漏斗架构”:

第一阶段(粗排召回

BM25 关键词检索 + 向量稠密检索)：两路并行各取 Top-20,通过 RRF（Reciprocal Rank Fusion,倒数排名融合算法） 合并去重，兼顾精确型号匹配与语义泛化理解。

第二阶段(精排重排序

Cross-Encoder Reranker)：使用 BGE-Reranker 或 Cohere Rerank 等交叉编码模型，对粗排召回的 20 个片段与用户问题做深度交叉注意力打分，精选出真正最相关的 Top-3 喂给大模型。

from collections import defaultdict
from typing import List
def reciprocal_rank_fusion(
dense_results: List[str], sparse_bm25_results: List[str], k: int = 60, top_n: int = 20
) -> List[str]:
"""RRF 公式: score(d) = sum( 1 / (k + rank(d)) ),无需对两路异构得分做复杂的分布归一化"""
rrf_scores = defaultdict(float)
for rank, doc_id in enumerate(dense_results, start=1):
rrf_scores[doc_id] += 1.0 / (k + rank)
for rank, doc_id in enumerate(sparse_bm25_results, start=1):
rrf_scores[doc_id] += 1.0 / (k + rank)
sorted_docs = sorted(rrf_scores.items(), key=lambda x: x[1], reverse=True)
return [doc_id for doc_id, _ in sorted_docs[:top_n]]
