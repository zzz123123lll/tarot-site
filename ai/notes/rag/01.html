SOURCE READING / 来源精读

CosineExplorer 用二维向量演示余弦相似度：相似度 = (A·B)/(|A|·|B|)，取值从 -1（完全相反）到 1（完全相同）；它衡量方向相似，不看向量长度。

逐点读懂

  1. 每个文本先被 Embedding 模型映射为向量，再用余弦相似度比较语义接近程度。
  2. 分子是点积，分母是两个向量模长的乘积。
  3. 二维向量可视化是为了先理解概念，再扩展到高维文本向量。
  4. 余弦值越接近 1，方向越接近；向量长度不影响方向相似性。

怎么对应本关练习

本关要求手写 L2 归一化、防除零、阈值过滤、排序返回；对应来源公式和 CosineExplorer 的教学顺序。

核心原理

在 StepByStep-RAG 的第一模块 CosineExplorer 中，作者指出理解 RAG 的起点是搞懂计算机如何衡量两段文字“意思相近”。通过嵌入模型(Embedding Model)，每段文本被映射为高维空间中的数值向量A 与 B。衡量它们语义接近程度的核心指标是余弦相似度(Cosine Similarity)：即两个向量夹角的余弦值（点积除以各自模长的乘积），取值范围为 [-1, 1]。夹角越接近 0 度，余弦值越接近 1,代表语义高度重合；与向量绝对长度（文章字数多少）无关，只看方向是否一致。

import numpy as np
from typing import List, Dict, Any

def cosine_similarity_search(
    query_vec: np.ndarray,
    doc_matrix: np.ndarray,
    docs_meta: List[Dict[str, Any]],
    top_k: int = 3,
    min_score: float = 0.75
) -> List[Dict[str, Any]]:
    query_norm = np.linalg.norm(query_vec) + 1e-10
    docs_norm = np.linalg.norm(doc_matrix, axis=1) + 1e-10
    similarities = np.dot(doc_matrix, query_vec) / (docs_norm * query_norm)

    valid_indices = np.where(similarities >= min_score)[0]
    if len(valid_indices) == 0:
        return []

    sorted_indices = valid_indices[np.argsort(similarities[valid_indices])[::-1]][:top_k]
    return [
        {
            "doc_id": docs_meta[i]["id"],
            "score": round(float(similarities[i]), 4),
            "text": docs_meta[i]["text"],
        }
        for i in sorted_indices
    ]

得分要点拆解

准确实现点积除以模长乘积并加 1e-10 防除零（4.5 分）；严格过滤低于 0.75 的噪音文档、支持返回空列表（5 分）；按降序输出结构化字典列表（3 分）。
