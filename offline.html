这个页面还没被缓存过

你现在处于断网状态,而这个页面之前没有存进你的浏览器,所以打不开——我们不会假装能打开,也不会偷偷把你送到首页。

先说明:19 个工具页正常情况下不会走到这里。你访问过一次工具盒之后,它们就已经存在浏览器里了,断网也能打开:

  • 图片压缩 / 证件照 / 图片转换 / 图片合成 PDF / 发票拼版 / PDF 合并 / 拆分 / 转图片 / 压缩;
  • JSON / Base64 / 正则 / 颜色 / 二维码 / JWT / Hash / URL / UUID / 日期。

会走到这一页的,通常是这两种情况:

  • 塔罗页:它是另一套页面(自己的 305KB 程序与字体),我们没有把它塞进预缓存——先联网打开它一次,之后断网就能用;
  • 你还没访问过工具盒首页:那样什么都还没存下来,先联网打开一次首页即可。

另外:压缩类工具要真正处理文件,还需要你「成功处理过一次文件」——压缩引擎(约 1MB)是那一步才存进浏览器的。
