关于 HEIC 解码器（libheif，LGPL-3.0）：我们做了什么

  • 没有修改上游代码：文件按原样分发，完整许可证文本在 /vendor/heic/LICENSE-libheif.txt。
  • 独立文件、可替换：它没有被编译进工具盒自己的代码，而是通过 <script> 单独加载；任何人都可以换成自己构建的同名文件。
  • 按需加载、用户决定：只有你在某个工具里点“用本地解码器转成 JPG”时才会下载（约 1.9MB），不点就不下载。
  • 源码可获取：见上表“对应源码 tarball”；版本号 1.23.2，与本站分发的文件一一对应。
  • 供应链核对：该 tarball 的 SHA-1 与 SHA-512 与 npm registry 公布值逐位一致后才引入。本站 vendor/ 下每个文件（共 221 个）的 SHA-256 清单随站点公开：/vendor/SHA256SUMS.txt，可直接下载对照校验。
  • 专利提醒（如实说）：HEIC 背后的 HEVC/H.265 存在专利池（如 MPEG LA、Access Advance）。开源许可证与专利授权是两件事；若你要把本站用于商业场景，建议就这一点单独咨询法务。

我们做了什么、没做什么

  • 全站是静态文件，没有服务端；没有上传接口，也没有把文件内容发出去的地方。
  • 唯一的第三方请求是 Cloudflare 的访问统计脚本（不含你的文件内容）；它不是我们主动要的追踪，也可以关掉。
  • 没有广告、没有登录、没有把文件送到别人的服务器上做处理。

整站 vendor/ 合计 7.25 MB,但**首屏一分钱都不用下**:只有你用到某个工具时才按需加载对应库(HEIC 解码器还必须你点确认)。
